多言語に対応しました Multi-Language Support

2026年2月3日 February 3, 2026

CLIBLOGに多言語対応機能を追加した。100以上の言語に翻訳できる。言葉の壁を越えるということは、思いを伝える範囲を広げるということだ。

ひとつの記事が、さまざまな言語で読まれる。その可能性を、できるかぎり自然な形で実現したいと考えた。

仕組みについて

多言語対応の仕組みは、シンプルだ。記事を書いて投稿する際に、翻訳したい言語を伝えるだけ。あとはClaude Codeが翻訳を生成し、すぐに公開される。

  1. 記事を書く
  2. 翻訳する言語を指定する
  3. 数秒で翻訳が完了する

読者は、自分のブラウザの言語設定に応じて、自動的に適切な言語で記事を読むことができる。もちろん、手動で言語を切り替えることも可能だ。

• • •

技術的な背景

翻訳データは、元の記事と紐付けて管理される。データベースには以下のような情報が追加された。

locale            -- 言語コード（ja, en, zh など）
original_post_id  -- 翻訳元の記事ID
translation_status -- 翻訳の状態

URLの設計

多言語コンテンツへのアクセスは、シンプルなパラメータで制御する。

/b/notf/my-article          → 自動選択
/b/notf/my-article?lang=ja  → 日本語
/b/notf/my-article?lang=en  → 英語

使い方

Claude Codeに話しかけるように、翻訳を依頼できる。

「この記事を英語と中国語に翻訳して」

これだけで、三つの言語で同時に公開される。特別な操作は必要ない。

これから

次のバージョンでは、以下の機能を予定している。

  • 画像の多言語対応
  • 翻訳の一貫性向上
  • コミュニティによるレビュー

Added multi-language support to CLIBLOG. You can now translate posts into over 100 languages. Crossing language barriers means expanding the reach of your thoughts.

One article, read in many languages. We wanted to make this possibility as natural as possible.

How it works

The multi-language system is simple. When you write and publish an article, just specify the languages you want. Claude Code generates the translations, and they're published immediately.

  1. Write your article
  2. Specify target languages
  3. Translations complete in seconds

Readers automatically see articles in their browser's language. They can also switch languages manually whenever they wish.

• • •

Technical background

Translation data is linked to the original article. The following information was added to the database:

locale            -- Language code (ja, en, zh, etc.)
original_post_id  -- Source article ID
translation_status -- Translation state

URL design

Access to multi-language content is controlled through simple parameters:

/b/notf/my-article          → Auto-select
/b/notf/my-article?lang=ja  → Japanese
/b/notf/my-article?lang=en  → English

How to use

Just ask Claude Code as you would in conversation:

"Translate this to English and Chinese"

That's all it takes to publish in three languages at once. No special steps required.
